## Objective

Build an enterprise network for a coursework assignment with separate network segments, reliable routing and a failover design.

## My contribution

I configured VLANs, inter-VLAN routing, multi-area OSPF, DHCP relay, SSHv2, dynamic PAT and failover. I completed configuration and evidence collection before writing the report so I could explain the network using test results.

## Verification and scope

I validated the configuration through connectivity and failover checks and documented the results. I also researched least-privilege access control lists and included them as a design proposal. Implementation and testing of the proposed ACLs were outside the completed work.
