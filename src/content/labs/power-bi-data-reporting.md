## Objective

Turn a coursework dataset into a dashboard that lets readers understand key findings without following the full analysis workflow.

## My contribution

I cleaned and validated the data, applied K-means clustering and built an interactive Power BI dashboard with filters, visual comparisons and KPI cards.

## Outcome

The dashboard let readers explore the results and compare groups. The dataset was from a general data analytics assignment. Checking source data and presenting the main findings clearly are skills I can bring to security dashboards and recurring reports.
