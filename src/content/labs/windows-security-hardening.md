## Objective

Address 10 CIS Benchmark findings in a Windows coursework environment and show that the resulting controls behaved as expected.

## My contribution

I tracked the findings with a checklist, applied firewall and audit settings, configured encryption and set up certificate-backed services. I recorded the changes and reviewed the evidence for each finding before finalising the report.

## Verification and outcome

I compared the firewall settings and certificates with the intended configuration, then reviewed failed authentication events in Event Viewer to confirm that audit events were being recorded. The project gave me practice connecting a security setting to the evidence it produces, a foundation for endpoint monitoring and security reporting.
