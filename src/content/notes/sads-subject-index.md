## Servers Administration & Security

This folder is for server administration concepts, configuration records, hardening notes, and revision material.

## Organisation

- Create one note for each service or topic.
- Record both the configuration and the reason behind it.
- Separate normal operation from security controls.
- Attach configuration samples or screenshots when they improve the explanation.
