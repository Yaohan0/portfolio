## Why I built it

I wanted one place that could hold both the polished work and the process behind it. The site separates class notes, practical labs, project builds, technical writeups, achievements, skills, and older material so each collection has a clear job.

## The content system

The portfolio is backed by structured Markdown collections. Yaohan Studio sits on top of those files so I can add, edit, organise, upload, and publish content without manually rebuilding every page.

## Still evolving

This is an ongoing build. I am refining the interaction design, improving how content is edited, and adding stronger project case studies as the work develops.
